The shipping entry is `LK_NetworkLobby`; both PLAY SOLO and ready Host/Join crews route through `ShipWorld.GameplaySceneName` to `LK_Bootstrap`. Bootstrap loads the six original content scenes. This milestone does not claim the later seven-day game or headset acceptance.

## Reproduce

Use Unity 6000.3.23f1. From the repository root, set `LK_UNITY` to `/Applications/Unity/Hub/Editor/6000.3.23f1/Unity.app/Contents/MacOS/Unity` and `LK_ADB` to `/Applications/Unity/Hub/Editor/6000.3.23f1/PlaybackEngines/AndroidPlayer/SDK/platform-tools/adb`.

```sh
"$LK_UNITY" -batchmode -nographics -projectPath "$PWD" -executeMethod LighthouseKeepers.Editor.OneLighthouseM1.Apply -quit -logFile artifacts/one/M1/authoring-final.log
"$LK_UNITY" -batchmode -nographics -projectPath "$PWD" -runTests -testPlatform EditMode -testResults artifacts/one/M1/editmode.xml -logFile artifacts/one/M1/editmode.log
"$LK_UNITY" -batchmode -nographics -projectPath "$PWD" -runTests -testPlatform PlayMode -testFilter 'SoloLobbyFlowTests;OfflineFusionSessionLoadsBootstrapAndSurvivesBoardUnload;NetworkRigTests;ReleaseSoloOverrideTests' -testResults artifacts/one/M1/playmode.xml -logFile artifacts/one/M1/playmode.log
"$LK_UNITY" -batchmode -projectPath "$PWD" -executeMethod LighthouseKeepers.Editor.OneLighthouseCapture.Run -logFile artifacts/one/M1/graphics.log
"$LK_UNITY" -batchmode -nographics -buildTarget Android -projectPath "$PWD" -executeMethod LighthouseKeepers.Editor.OneLighthouseM1.Build -quit -logFile artifacts/one/M1/android.log
"$LK_ADB" -s 2G0YC1ZG32048T install -r Builds/LighthouseKeepers-M1.apk
```

The repeatable build-list menu is **Lighthouse Keepers/Apply Ship Build Scenes**. The migration removes scene/prefab effects using Unity APIs; no scene YAML was edited by hand. Standard Unity serialization whitespace and field-order changes are retained.
