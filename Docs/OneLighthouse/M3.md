M2 56c947a is the accepted baseline. M3 headset acceptance is pending.

## Behavior and controls

- Day 1 and Day 2 data are unchanged. Day 3 requires generator, pipe and broadcast; Day04 is an explicit placeholder copy, so completing Day 3 permits sleep into the next authored day. Development lobby includes PLAY DAY 3; release excludes both day shortcuts.
- One `EmergencyLighting` listens to day-owned power. Interior materials/fixtures and cached lights pulse smoothly red over 1.5 seconds with a nonzero minimum; a quiet original alarm loops. Restoring power stops the alarm and fades warm over one second. Existing powered bake remains intact; no camera overlay or hard flashes.
- The 1.55 m-wide F4 console is mounted slightly west of centre on the north glazing wall, leaving the beacon and stair route clear. The original west side is a stairwell opening, so it is unsuitable for standing. The walk test checks access to the north standing area using the existing rig and collision.
- Console has 22 direct-grip controls: MAIN, frequency/trim/gain knobs, four code buttons, eight utility buttons and six auxiliary toggles. Grip buttons to depress/click, grip switches to flip, grip knobs and twist the controller around the shaft. Utility controls animate/click without additional puzzle gates.
- MAIN requires generator power. Tune to 156.80 MHz within ±0.04 MHz for one second. Read the separate `CodeSource` call card; enter RED → BLUE → AMBER → GREEN. Wrong input resets the code only. Grab the microphone and hold trigger continuously for three seconds; releasing grip/trigger cancels the unfinished transmission. Generated tuning static/tone, radio chatter and reply tones accompany the loop; there is no recorded speech.
- Shared low-poly cabinet meshes/materials, moving needle, two bouncing meters, backlit controls, status lamps and a coiled microphone cord provide the foundation. Accepted generator mechanics/feedback, hands, wrench, flood, bed and clean HUD are preserved.
