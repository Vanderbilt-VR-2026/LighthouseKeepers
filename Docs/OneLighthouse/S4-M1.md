## Controls and voice

In the Editor Game view: WASD move, Q/E turn, right mouse drag to look; **F near the F3 bed** votes to sleep once tasks are finished. This additional binding is Editor-only. Quest uses its existing grip button.

Photon Voice for Fusion is pinned to the official Fusion Hub package commit `1b93daae7984009cedc51f761a198d145fcf44ad` (2.63.0). It follows the existing Fusion room and `us` region, using the separately supplied Voice App ID. Open mic starts only after permission. Watch Menu has mute/unmute; muting stops capture and transmission. Remote mono audio follows the interpolated remote head with linear attenuation from 2–12 m. Offline PLAY SOLO creates no voice client or recorder and requests no microphone permission.

## Install on a second Quest

1. Use SideQuest to install `LighthouseKeepers-S4M1-7cc8702.apk` from the path above on the teammate's Quest.
2. Open **Lighthouse Keepers** from Unknown Sources; keep Wi-Fi on for crew play.
3. One player chooses **HOST CREW**. The other chooses **CREW OPTIONS**, enters that host's current code, closes the keypad, and chooses **JOIN CREW**.
4. Both choose **SIGNAL READY**; the host chooses **BEGIN WATCH**. Allow microphone access when asked. Use Watch Menu to mute.

Both clients need the same S4 build; the public S3 preview intentionally uses a different matchmaking version. PLAY SOLO remains offline and does not start Photon Voice.
