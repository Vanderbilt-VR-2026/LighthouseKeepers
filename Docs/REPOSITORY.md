## Archived work

The November 3 cleanup was explicitly requested by the lead. Every remote branch tip was saved and verified on GitHub before branch removal or replacement, including unmerged teammate work and the former sprint branch tips. See the [archive index](Archives/Branches-2026-11-03.md) for exact commits, tags and open PRs at archive time.

This cleanup does not merge archived feature work. Local branches, working copies and uncommitted files are left alone. The published Sprint 1, Sprint 2, Sprint 3 and historical preview releases remain available.
