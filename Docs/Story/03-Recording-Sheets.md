# RECORDING SHEETS — Lighthouse Keepers, Sprint 5

You record **both** roles. Use the same setup as last time: phone voice memo, quiet room, phone about a
hand's width from your mouth, then the same conversion and ElevenLabs steps.

## How to record (simple version)
1. Record **one file per line**. Say the line once, cleanly. Don't say the ID or the number out loud.
2. If you mess up, stop and start that file again; don't leave mistakes in the file.
3. Leave about half a second of silence before and after.
4. Name each file exactly as in the **File** column (lowercase, `.wav` after conversion). If your phone
   names them "Memo 12", put them in order and rename later. The order here is the order you record.
5. Keep each line under 10 seconds. Most are 3–6.
6. Harbor master: talk like a tired, kind dock boss on a radio. **Not** a movie voice. Quiet confidence.
7. The Drowned: whisper **close** to the phone, slowly, almost gently. The creepiness comes from how
   calm it is. Record these in your normal voice; the ElevenLabs Voice Changer does the old woman
   (Margaret), child (Lottie) and deep man (Walter) presets afterwards.
