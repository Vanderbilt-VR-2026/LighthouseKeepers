# Play together on two Quests

You need two Quest headsets, Wi-Fi, a computer, a USB cable that transfers data, and **the same current APK file on both headsets**. Ask the lead for `LighthouseKeepers-Playtest.apk`. The older Sprint 3 and co-op preview downloads cannot join this test build.

## 1. Allow game installation

On the phone paired with each headset, open **Meta Horizon → Devices → your headset → Developer Mode**, and turn it on. If the option is missing, complete Meta's developer account setup first, then reopen the phone app. [Meta's setup help](https://developers.meta.com/vr/documentation/unreal/ts-mqdh-getting-started/).

## 2. Install the game on each headset

Install [SideQuest on your computer](https://sidequestvr.com/setup-howto), choosing the desktop installer that supports local APK files. Connect one Quest with USB, put it on, and accept **Allow USB debugging**. Select **Always allow from this computer** if offered. In SideQuest, choose **Install APK file from folder** and select `LighthouseKeepers-Playtest.apk`. Wait for it to finish. Repeat with the other Quest.

## 3. Open the same crew

Both headsets: turn Wi-Fi on, open **Library → Unknown Sources → Lighthouse Keepers**, and allow microphone access for voice chat.

1. **Host:** press **PLAY → HOST / PLAY ALONE**. Read the six-character code to your friend.
2. **Friend:** press **PLAY → JOIN CREW**, enter that code, then **JOIN CREW**.
3. **Host:** check that two names appear and press **START**. There is no READY step.
4. Both arrive in the House. To rejoin later, enter the same code again; the running watch loads automatically.

Left stick moves; right stick turns; grip grabs/squeezes; trigger talks into the broadcast mic; B recalls your objective. Read the House board. Finish the tasks, then **both** visit the F3 bed and press grip. Watch Menu lets you mute your microphone or return to the lobby.

**Can't join?** Check Wi-Fi, the code and that both installed the exact same APK. Start a fresh crew if the host has left. **HOST / PLAY ALONE → START** also works without a partner. Without Wi-Fi it says **No connection — Play offline**; press START. Both online keepers need **NETWORK VERSION LK-S5-PLAYTEST1**.

This test build replaces the app named **Lighthouse Keepers**. Sprint 2 remains separate as **Lighthouse Keepers S2**. The original Sprint 2 and Sprint 3 releases remain available on GitHub.
