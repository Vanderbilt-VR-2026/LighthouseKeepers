# Lighthouse Keepers agent instructions

Read [.AGENTS/README.md](.AGENTS/README.md) before changing this repository. It applies the user-supplied AI Game Development Lexicon to this Unity project. The full reference is in [.AGENTS/AI_GAME_DEVELOPMENT_LEXICON.md](.AGENTS/AI_GAME_DEVELOPMENT_LEXICON.md).

The current experience goal is **tense teamwork with recovery moments**, eventually surviving together to the top of the lighthouse. Storm Watch is the current two-player, three-watch implementation, targeting roughly ten minutes total. See `Docs/StormWatch.md` for the agreed design and `Docs/Verification/StormWatch` for actual evidence. The older First Watch entry remains a local, one-floor rehearsal. Do not conflate implementation, transport testing, or headset acceptance.
