# Lighthouse Keepers agent instructions

Read [.AGENTS/README.md](.AGENTS/README.md) before changing this repository. It applies the user-supplied AI Game Development Lexicon to this Unity project. The full reference is in [.AGENTS/AI_GAME_DEVELOPMENT_LEXICON.md](.AGENTS/AI_GAME_DEVELOPMENT_LEXICON.md).

The current experience goal is **tense teamwork with recovery moments**, eventually surviving together to the top of the lighthouse. First Watch is a local, one-floor rehearsal; do not describe it as synchronized multiplayer or a complete tower campaign.
