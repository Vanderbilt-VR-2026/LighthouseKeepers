# Sprint 1 — Lighthouse Environment

**[Download the Sprint 1 game (APK)](https://github.com/Vanderbilt-VR-2026/LighthouseKeepers/releases/download/sprint1-quest3-20261001/LighthouseKeepers-Sprint1-Environment.apk)**

The original lighthouse environment foundation for Meta Quest 3. This is an early exploration build; the later pipe, generator and radio day loop is in Sprint 3.

## Install on Quest

1. Download the **APK** above. APK means the game; MP4 means the video.
2. Enable **Developer Mode** in the Meta Horizon phone app for your Quest. [Setup help](https://github.com/Vanderbilt-VR-2026/LighthouseKeepers/blob/main/Docs/INSTALL.md).
3. Connect the Quest to your computer with USB and accept **Allow USB debugging** inside the headset.
4. In SideQuest on your computer, choose **Install APK file from folder** and select the downloaded APK. Or use `adb install -r <file>.apk`.
5. Open **Library → Unknown Sources** on the Quest, then select the app listed below.

Open **Lighthouse Keepers** and explore the lighthouse. **Left stick** moves; **right stick** snap-turns.

Sprint 1 uses the same app name/package as Sprint 3 and replaces it when installed. Sprint 2 installs separately.
